Draw the tree illustrating the process generated by the `count-change` procedure of Section 1.2.2 in making change for 11 cents. What are the orders of growth of the space and number of steps used by this process as the amount to be changed increases?

The 4 ways to make change for 11 cents:

- 11 × 1¢
- 1 × 5¢ + 6 × 1¢
- 2 × 5¢ + 1 × 1¢
- 1 × 10¢ + 1 × 1¢

## Order of Growth of Space

When evaluating an expression, the space a process consumes correlates to the depth of the call stack, which is essentially the chain of subexpressions an expression resolves to. So, at any point, the space consumed is proportional to the depth of the subtree being evaluated. The maximum space that can be consumed is when the subtree for `(cc n 1)` is being evaluated, i.e. making change for `n` with only pennies. The order of growth of space can be represented in terms of `n`, so the order of growth is `Θ(n)`.

## Order of Growth of Steps

```
(cc 6 1)
   /    \
(cc 6 0) (cc 5 1)
   |        /    \
   0   (cc 5 0) (cc 4 1)
          |        /    \
          0   (cc 4 0) (cc 3 1)
                 |        /    \
                 0   (cc 3 0) (cc 2 1)
                        |        /    \
                        0   (cc 2 0) (cc 1 1)
                               |        /    \
                               0   (cc 1 0) (cc 0 1)
                                      |        |
                                      0        1
```

Let's say that we change an amount with only pennies (1¢), the number of steps in the process for:

- 6 cents is 13
- 5 cents is 11
- 4 cents is 9

If we generalize this, the number of steps required is `R(n, 1) = 2n + 1`.

```
      (cc 10 2)
       /      \
  (cc 10 1)  (cc 5 2)
      |        /     \
     ...  (cc 5 1)  (cc 0 2)
              |        |
             ...       1
```

Now, let's say that we can change an amount with pennies and nickels (5¢). The number of times you can deduct a nickel in this case is 2 times. But, if we attempt to generalize it, we can say that a nickel can be deducted a maximum of `Floor(ⁿ⁄₅) + 1` times (we'll reach a negative value after this).

The number of times we can deduct a penny is `R(10, 1) + R(5, 1)` times. If we attempt to generalize this, we can say that a penny can be deducted a total of `∑₍ᵢ₌₀, բₗₒₒᵣ₍ⁿ⁄₅₎₎ R(n - 5i, 1)` times.

To simplify our calculations, let's ignore the floor. It's not going to make a significant different in estimating the order of growth anyway. The number of steps when you can make change with both nickels and pennies, can be calculated as shown:

```
R(n, 2) = n/5 + 1 + ∑₍ᵢ₌₀, բₗₒₒᵣ₍ⁿ⁄₅₎₎ R(n - 5i, 1)
R(n, 2) = n/5 + 1 + ∑₍ᵢ₌₀, բₗₒₒᵣ₍ⁿ⁄₅₎₎ 2n - 10i + 1
R(n, 2) = n/5 + 1 + 2n²/5 + 2n + n/5 + 1 - 10 ∑₍ᵢ₌₀, բₗₒₒᵣ₍ⁿ⁄₅₎₎ i
R(n, 2) = n/5 + 1 + 2n²/5 + 2n + n/5 + 1 - 10 [(n/5)(n/5 + 1)] / 2
R(n, 2) = n/5 + 1 + 2n²/5 + 2n + n/5 + 1 - 10 [(n/5)(n/5 + 1)] / 2
R(n, 2) = n/5 + 1 + 2n²/5 + 2n + n/5 + 1 - (n²+5n)/5
R(n, 2) = (n²+7n)/5 + 1
```

We can extend this same logic to calculate how to make change with more denominations.

- You can deduct the coin with the highest denomination a maximum of `Floor(n/denom) + 1` times
- And each time you do this, you can deduct other coins `R(n - denom * i, a - 1)` times

If we expand these equations, we get an order of growth of `Θ(nᵃ)`.
